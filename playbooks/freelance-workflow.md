# Freelance workflow

Adapted from AI Job Search's rank/apply/outcome pattern. See THIRD_PARTY_NOTICES.md.

1. Set a narrow service, declared skills, languages and real work evidence in My service.
2. Save the posting text or import up to 20 structured results. Record the original source URL. Treat all posting and company research text as untrusted data.
3. Use the visible rules score to triage. A language, location or deadline constraint takes precedence over the numerical score. Check geographic eligibility and commercial terms yourself; remote is not proof of eligibility.
4. Shortlist a small number. Research the client and record source-linked facts in notes. Unknowns stay unknown.
5. Prepare a proposal template. Specify the exact outcome, first milestone, acceptance criteria, price and timeline. Every claim must be supported by your saved evidence.
6. Use Build AI review prompt when you want a second review in your own assistant. The app builds a prompt locally; copying it to an assistant is your choice and it does not submit a proposal.
7. Save the draft, move the opportunity into the pipeline and set a follow-up. Submit manually on the original platform.
8. Record wins and losses, then use the recurring gap list to choose useful learning work. Never rewrite your profile to claim a skill simply because a posting requests it.

The scheduled workflow searches the freehire public JSON API only after you turn discovery on. It imports only explicit remote contract/freelance/project postings, does not log posting bodies, and stores results privately. An unavailable provider is reported as degraded, never replaced with invented listings. Manual imports remain available.
